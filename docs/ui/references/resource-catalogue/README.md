# Resource Catalogue visual references

These SVG files are versioned implementation-reference pictures derived from `docs/ui/resource-catalogue-wireframes.md`.

They preserve the visual intent that is otherwise easy to lose in chat screenshots:
- dense operational Resource list;
- current-state-first Resource Overview;
- read-only temporal History;
- lightweight New Resource modal.

They are deliberately stored as SVG rather than opaque screenshots so layout/text changes are reviewable in Git and future UI work can update them together with the wireframe contract.

Semantic precedence:
1. canonical domain/requirements/architecture owners;
2. `docs/ui/resource-catalogue-wireframes.md`;
3. these SVG illustrations.

Sample names, addresses, scopes and people/teams are illustrative only.
