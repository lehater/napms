# NAPMS documentation map

The repository keeps current product truth separate by concern.

- `domain/` — living Strategic/Tactical DDD and deferred domain seams.
- `requirements/` — accepted Wave-1 functional, quality and acceptance baseline.
- `architecture/` — target architecture, drivers, views, ownership and transition constraints.
- `decisions/` — durable ADRs.
- `engineering/` — implementation contracts, tests/gates and cross-cutting engineering policies.
- `baseline/` — accepted G2/G3/G4 snapshots and migration provenance.

Historical reconstruction, Legacy evidence and superseded DDD experiments remain in `lehater/sssr_xlam` and are not product truth here.
